# URF Spine Public

Public audit surface for the URF spine layer.

This repository is a sanitized public mirror of the private `urf-spine` repository.

## Status

- invariant-anchor-layer
- certified-obstruction-layer
- reduction-template-layer
- certificate-verified
- release-certified
- not theorem-prover-complete
- not a primary mathematics-closure repository

Claims apply only under declared constraints.

## Verify the public example

From the public checkout, run `python3 tools/verify_public_spine_surface.py`.
The script checks the included certificate and its declared scope. See [Quickstart](QUICKSTART.md).

## What this public mirror contains

- public status surface
- citation metadata
- scope limitations
- external status lock
- minimal verifier
- minimal finite certificate example

## What this public mirror does not contain

- unpublished proof attempts
- private provenance
- sensitive certificates
- private hashes
- internal research logs
- full reduction scripts
- private release bundles

## Boundary

Build success, CI success, dashboards, ledgers, axioms, admits, sorry, placeholder witnesses, or certificate checks do not constitute theorem-level closure.
